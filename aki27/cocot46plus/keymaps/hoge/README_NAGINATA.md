# 薙刀式（hoge キーマップ）の使い方

ビルドは成功しているが「薙刀にならない」場合、**キーボード側で薙刀式を有効にする**のと **Mac 側で日本語入力を用意する**の両方が必要です。

---

## 1. キーボード側：薙刀式の出し方

このキーマップでは次のどれかで薙刀式を使えます。

| 操作 | 説明 |
|------|------|
| **MO(4) を押したまま** | スペース左隣の「薙刀レイヤー」キーを**押している間だけ**薙刀式。離すと通常レイヤーに戻る。 |
| **DF(4) を押す** | 親指付近の **DF(4)** キーを押すと、**デフォルトレイヤーが薙刀式**になる（常時薙刀）。戻すには **DF(0)** を押す。 |
| **H と J を同時押し** | 薙刀式オン（ソフトウェアでフラグがオン）。 |
| **F と G を同時押し** | 薙刀式オフ。 |

- まずは **MO(4)**（薙刀レイヤーキー）を押したまま、`a` `i` `u` など打ってみて、Mac 側で日本語が変換されるか確認するとよいです。
- 常時薙刀にしたい場合は **DF(4)** でデフォルトを薙刀レイヤーに切り替えてください。

---

## 2. Mac 側：日本語入力の準備

`config.h` で **NAGINATA_EDIT_MAC** と **MAC_LIVE_CONVERSION** が有効なので、**US 配列 + 日本語ローマ字入力 + ライブ変換** を想定しています。

### 2.1 日本語入力ソースを追加

1. **システム設定** → **キーボード** → **入力ソース**
2. **＋** で **日本語** を追加
3. 入力モードは **ローマ字入力**（またはお好みでかな入力）のままでOK

### 2.2 日本語に切り替える

- **Ctrl + Space** または **⌘ + Space** で、**日本語** に切り替える
- メニューバーの入力メニューで「あ」や「A」になっていることを確認

### 2.3 ライブ変換（推奨）

- **システム設定** → **キーボード** → **日本語入力の設定**（または「入力ソース」で日本語を選んで設定）
- **ライブ変換** をオンにすると、薙刀式で打ったローマ字がその場で漢字変換されやすくなります（MAC_LIVE_CONVERSION と相性が良いです）。

---

## 3. 動作確認の流れ

1. Mac で入力ソースを **日本語** に切り替え（⌘+Space など）
2. キーボードで **MO(4)** を押したまま、または **DF(4)** で薙刀をデフォルトに
3. 薙刀式の配列で「あいうえお」など打つ（例: 左手人差し指で `a`、中指で `i` など）
4. Mac 側でローマ字→かな・漢字に変換されれば成功

---

## 4. レイヤーと LED

- **_NAGINATA レイヤー（4）** に入ると **LED が黄色** になります。黄色になっていれば薙刀レイヤーには入れています。
- レイヤーは入っているのに日本語が出ない場合は、**Mac 側の入力ソースが日本語か** を確認してください。
